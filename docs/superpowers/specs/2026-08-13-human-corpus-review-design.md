# 四來源 Text-to-Gloss 人工校訂與訓練匯入設計

日期：2026-08-13
狀態：使用者已批准設計方向，待書面規格複核後實作

## 1. 目標

將四個來源的完整中文—臺灣手語 Gloss 句對整理成四份人工校訂 Excel。資料以「中文＋Gloss」去重，重複內容只評一次，但保留全部原始來源 ID。

完成校訂後，系統必須驗證工作簿、產生 reviewed JSONL、建立防洩漏切分，並用 manifest、雜湊與訓練前檢查證明校訂資料確實進入模型。

本輪只審中文語意與 Gloss 詞彙／語序。NMS、手形、動作方向與地區變體只保留「需影片確認」標記，不阻擋 Text-to-Gloss 訓練。

去重比較前去除中文首尾空白；Gloss 將全形斜線轉為半形斜線、去除 token 首尾空白並忽略空 token。工作簿仍顯示代表列的原始文字。

相同句對的全部原始 ID 放在「重複來源 ID」。代表 ID 為原始檔第一個出現的 ID。四個來源彼此不跨檔去重，以保存來源與授權追蹤。

## 3. 四份工作簿

- 人工校訂_文化部臺灣手語語料庫_5125筆.xlsx
- 人工校訂_中正大學臺灣手語線上辭典例句_542筆.xlsx
- 人工校訂_規則模板合成句_967筆.xlsx
- 人工校訂_論文例句_295筆.xlsx

每份包含：

1. 填寫說明：規則、範例與 Gloss 格式。
2. 人工校訂：一列一個不重複句對。
3. 進度統計：未填、通過、需更正、排除、需複審、可匯入與錯誤筆數。
4. 欄位選項：下拉選項、欄位定義與機器匯入規格。

工作簿凍結標題列與識別欄、啟用篩選、長文字換行。人工欄位用淡色、不可修改欄用灰底。狀態與錯誤另有文字欄，不能只靠顏色。

## 4. 人工校訂欄位

### 4.1 固定原始欄位

1. 穩定ID
2. 重複來源ID
3. 資料來源
4. 來源子類型
5. 原始中文
6. 原始Gloss
7. 來源說明
8. 影片或文獻連結
9. 原始資料指紋

來源子類型分別保存文化部主題、中正辭典詞條、合成模板或論文名稱。沒有 URL 時保存文獻引用文字。

### 4.2 主審欄位

1. 主審判定
2. 問題類型
3. 更正中文
4. 更正Gloss
5. 更正理由
6. 需影片確認

不包含主審姓名與日期。

主審判定：通過／需更正／排除／需複審。

問題類型：

- 中文語意錯誤
- Gloss詞彙錯誤
- Gloss語序錯誤
- 漏詞
- 多餘詞
- 拼寫或格式問題
- 中文與Gloss不對應
- 重複或資料衝突
- 需影片或上下文確認
- 其他

需影片確認：否／是。選「是」本身不阻擋已確認的中文與 Gloss 進入訓練。

### 4.3 複審欄位

1. 複審判定
2. 複審更正中文
3. 複審更正Gloss
4. 複審意見

不包含複審姓名與日期。複審只處理主審判定為「需複審」的資料。複審判定為：通過／需更正／排除／仍需複審。

### 4.4 自動欄位

1. 最終判定
2. 最終中文
3. 最終Gloss
4. 可匯入訓練
5. 資料檢查結果

Excel 公式只提供即時提示。匯入程式必須獨立重算，避免公式被改動或 Excel 引擎差異。

## 5. 最終值規則

| 情況 | 最終結果 |
|---|---|
| 主審通過 | 原始中文＋原始 Gloss，可匯入 |
| 主審需更正 | 更正中文；空白沿用原始中文。更正 Gloss 必填，可匯入 |
| 主審排除 | 不輸出、不匯入 |
| 主審需複審，複審未完成或仍需複審 | 待複審、不匯入 |
| 複審通過 | 原始中文＋原始 Gloss，可匯入 |
| 複審需更正 | 複審更正中文；空白沿用原始中文。複審更正 Gloss 必填，可匯入 |
| 複審排除 | 不輸出、不匯入 |

補充規則：

- 排除必須選問題類型並填更正理由或複審意見。
- Gloss 接受半形或全形斜線，匯入時統一成半形斜線。
- 正規化後 Gloss 不得為空或含空 token；單一 token 允許。
- 主審不是需複審時，複審欄不得影響最終結果。

## 6. 訓練匯入管線

四份 Excel 先驗證結構、指紋與人工欄位，再產生四份 reviewed JSONL、combined_reviewed.jsonl 與 review_manifest.json。之後依凍結測試集與來源群組切分 train/dev/test，產生結構化 JSON target，通過 preflight 後才可啟動 QLoRA。

不覆蓋原始 JSONL。輸出至 data/reviewed：

- tslcorpus_reviewed.jsonl
- twtsl_sentences_reviewed.jsonl
- synth_reviewed.jsonl
- papers_reviewed.jsonl
- combined_reviewed.jsonl
- review_manifest.json
- review_errors.jsonl

reviewed 記錄保存穩定 ID、全部來源 ID、最終中文、最終 Gloss、來源、來源分組、判定、問題類型、理由、需影片確認、原始指紋與工作簿版本。

## 7. 驗證與失敗策略

匯入採 fail-closed：無法證明正確的資料一律不進訓練。

### 7.1 工作簿完整性

- 檔名、來源代碼、工作表與表頭必須符合規格。
- 穩定 ID 唯一完整，筆數分別為 5,125／542／967／295。
- 原始中文、原始 Gloss、來源 ID 或指紋遭修改時拒絕該列。
- 四份內容必須與產生時 manifest 雜湊對帳。

### 7.2 人工欄位完整性

- 空白判定視為未完成，不匯入。
- 需更正缺更正 Gloss 時報錯。
- 排除缺問題類型或理由時報錯。
- 需複審未得到有效結論時保持待複審。
- 無效選項、異常 Gloss、空字串與重複穩定 ID 均報錯。

### 7.3 防止資料洩漏

- 核心測試、文化部留存測試與論文留存測試的凍結 ID／中文／Gloss／群組不得進 train 或 dev。
- 校訂可更新測試參考答案，但不得改變測試角色。
- 文化部按對話、中正辭典按詞條、合成句按模板、論文按論文來源分組；群組不得跨 train/dev/test。

## 8. 證明資料確實進入訓練

必須同時具備：

1. 匯入 manifest：逐來源記錄原始、去重、未填、通過、更正、排除、待複審、錯誤、輸出筆數與 SHA-256。
2. 切分 manifest：記錄 train/dev/test 來源組成、唯一 ID、加權前後筆數及洩漏檢查。
3. 訓練 preflight／日誌：重新核對 train/dev 的 manifest 雜湊、來源分布與 review 狀態；有 pending、筆數或雜湊不符即停止。

正式訓練前執行 smoke test，從四個來源各抽至少一筆，確認最終中文進 prompt、最終 Gloss／JSON target 進 labels、更正值取代原始值，排除與未完成複審不在 dataset 中。

## 9. 測試與驗收

自動測試：

- 四來源載入、正規化、去重與來源 ID 聚合。
- 通過、需更正、排除、需複審各路徑。
- 中文空白回退、全形斜線及單 token Gloss。
- 指紋不符、缺更正 Gloss、無效選項與未完成複審。
- frozen test 洩漏、group split、manifest 與 SHA-256 對帳。
- 訓練 dataset smoke test。

工作簿驗收：

- 四份工作簿的所有工作表完成視覺渲染檢查。
- 標題、長文字、下拉選單、篩選與凍結窗格可用。
- 進度統計筆數一致且無公式錯誤。
- 每來源隨機抽查至少 10 筆與原始 JSONL 對帳。

完成條件：

- 四份 Excel 共 6,929 個不重複句對。
- 重複句對保留全部原始來源 ID。
- 匯入工具產生 reviewed JSONL、錯誤報告與 manifest。
- 切分與 preflight 能證明有效資料被訓練程式讀取。
- 原始 JSONL 與凍結測試角色未被破壞。

## 10. 非目標

- 本輪不做模型輸出與參考答案的 A/B 盲測；該表用於重訓後的模型成效評估。
- 本輪不要求逐筆 1–5 分評分。
- 本輪不裁定 NMS、手形、動作方向或地區變體。
- 本輪不直接正式訓練；先完成工作簿、匯入、驗證與 smoke test，再由使用者決定訓練版本。

# RAG 檢索增強實驗報告：兩個問題的實證答案

日期：2026-08-07
起因：使用者實測「前幾天我喝水、吃東西的時候覺得牙齒很痛耶」翻錯，並提出兩個問題：
①再爬更多語料庫長句有無幫助？②文獻中的訓練方法哪個能提高資訊量與準確度？

---

## 問題①：再爬更多長句 → **沒有幫助**

三項證據：

**1. 該句連同正確答案已在訓練集內**

```
語料庫原句：前幾天我喝水、吃東西的時候覺得牙齒很痛耶，
      Gloss：前幾天/東西/吃/水/喝/牙齒/痛      ← 使用者期望的正確答案
狀態：[train]
```

模型看過這句、學過正確答案，仍翻成 `我/喝水/吃東西/牙齒/痛/幾天`。**不是覆蓋問題。**

**2. 語料庫已全數爬完**：本地 407 段落／5,272 句即文化部語料庫完整內容，沒有更多可爬。

**3. 訓練集內長句復現率 0/6**（2026-08-06 診斷）：模型對長句是「學不起來」而非「沒學過」。

> 結論：再爬同類資料只會加深同一問題。資料量不是瓶頸。

---

## 問題②：文獻方法評估

錯誤拆解（使用者的例句）：

| # | 錯誤 | 期望 | 模型輸出 |
|---|---|---|---|
| 1 | 時間詞位置 | **前幾天**/… | …/痛/**幾天**（句末，違反規則5） |
| 2 | 動賓未拆 | **水/喝**、**東西/吃** | **喝水**、**吃東西**（保留中文複合詞） |
| 3 | 多餘主語 | （省略） | **我** |

| 文獻 | 方法 | 判斷 |
|---|---|---|
| CCL24-Eval ＋ 工研院 ITRI | RAG／ICL：推理時檢索相似例句入 prompt | **實測（見下）** |
| SCOPE (AAAI-25) | 上下文翻譯 | 對話題前置有用，但此句錯的是句內規則 |
| SignAlignLM | 多任務混訓防遺忘 | 不直接針對此錯誤 |
| Gemma 官方 | QLoRA | 已採用 |

RAG 是唯一能解釋「答案就在資料裡卻取不出來」的方法，故實測之。

## RAG 實測結果

### 對「訓練集內」的句子：大幅改善

| | 輸出 |
|---|---|
| 無 RAG | `我/喝水/吃東西/牙齒/痛/幾天` |
| **有 RAG** | `前幾天/我/水/吃/東西/喝/牙齒/痛` |
| 期望 | `前幾天/東西/吃/水/喝/牙齒/痛` |

3 個錯誤修好 2 個：時間詞回句首 ✅、複合詞拆成 O-V ✅；殘留多餘「我」與「水/東西」順序。

### 對「未見過」的 33 句 test：反而變差

| 設定 | BLEU-4 | ROUGE-L | Exact Match | 可播放率 | 平均檢索命中 |
|---|---:|---:|---:|---:|---:|
| **無 RAG（採用）** | **82.47** | **88.20** | **75.76%** | **97.18%** | — |
| RAG 多輪注入, 門檻 0.05 | 76.44 | 84.07 | 66.67% | 95.65% | 2.64 |
| RAG 多輪注入, 門檻 0.5 | 75.56 | 79.11 | 66.67% | 96.97% | 0.36 |
| RAG 單輪內嵌, 門檻 0.5 | 79.66 | 86.18 | 69.70% | 97.10% | 0.36 |

**結論：RAG 目前不宜預設啟用。** 33 句 test 皆為短日常句，檢索到的是相似度僅 0.1–0.2 的雜訊，干擾大於幫助。

### 過程中修掉的兩個實作缺陷（都有實證）

**缺陷一：RAG 靜默失效。** 初版在 JSON 模式下每次檢索結果都是空的——`build_json_targets` 會清掉句尾標點（`…痛耶，`→`…痛耶`），而檢索用語料庫原文查表，鍵值對不上就靜默跳過。若未逐筆檢查 `rag` 欄位就會誤以為「RAG 無效」。

**缺陷二：多輪注入破壞格式遵循。** 把例句做成多輪對話（user/assistant 交替）後，v8 對短句**直接回聲輸入而不輸出 JSON**（「謝謝」→ raw 就是「謝謝」），33 句中 3 句變成空輸出。原因是 v8 以**單輪**格式微調，多輪屬分布外輸入。改為把例句內嵌在同一個 user turn 後，空輸出消失、指標從 66.67% 回升到 69.70%（仍低於不用 RAG 的 75.76%）。

## 附帶發現：JSON 目標的標註 bug

`build_json_targets.py` 的 `WH_HINTS` 含「幾」，導致「前**幾**天」被判為 wh 疑問句：

```
前幾天我喝水…牙齒很痛耶 → question_type: "wh"（錯，非疑問句）
                        nonmanual: "疑問表情搭配句末疑問詞"（錯）
```

**訓練標籤本身就是錯的**，模型只是忠實學習。需修正 WH 判定（例如「幾」需搭配「幾個／幾點／幾歲」等疑問語境，或排除「前幾天／好幾天」等固定用法），修好後重訓才能改善此類句子的 NMS 正確率。

---

## 建議（依投報率）

1. **修 WH 判定 bug 並重訓**（成本低、影響明確）——目前含「幾」的非疑問句都會被錯標。
2. **RAG 設為可選、預設關閉**；若要用，僅在高相似度（≥0.5）且輸入為長句時啟用。程式已就緒（`--rag N --rag-min X`）。
3. **不要再爬同類語料**——已證實非資料量問題。
4. 若要解「多餘主語」與「O-V 順序」，需 SCOPE 的上下文翻譯或母語者標註，非現有方法可及。

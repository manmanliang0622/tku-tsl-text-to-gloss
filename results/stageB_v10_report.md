# Stage B v10：長度平衡取樣（長句大幅改善，短語退步的取捨）

日期：2026-08-08
起因：使用者回報 3 個長句翻譯錯誤，要求自動化測試語料庫輸出並提升正確率。

## 1. 先做自動化診斷，而非直接調模型

新增 `scripts/audit_corpus_outputs.py`：抽樣語料庫長句 → 逐句問模型 → 依
CCL24-Eval 分類法歸類錯誤，另量三項使用者回報的系統性問題。

**v9 在 60 句語料庫長句（皆在訓練集內）的表現：**

| 指標 | 值 |
|---|---:|
| Exact Match | 8.33%（5/60） |
| 詞彙替換／混合 | 39 句 |
| Gloss 缺失 | 15 句 |
| **輸出短於參考答案** | **70%**（平均 5.3 vs 6.4 詞） |
| 情態詞遺漏 | 10% |

## 2. 根因：訓練資料長度分布嚴重偏斜

| Gloss 長度 | 佔訓練集 |
|---|---:|
| ≤4 詞 | **54.9%** |
| 5–7 詞 | 34.8% |
| ≥8 詞 | **10.4%** |

模型被短句主導，學到「傾向產生短輸出」。使用者回報的漏詞（漏「要」、漏「水」）
正是此偏差的直接表現，**不是模型不懂語法**。

## 3. 對策與結果：長度平衡取樣

`split_data.py --length-balance`：train 依 Gloss 長度分桶重複（≤4 ×1、5–7 ×2、
≥8 ×4），train 6,102 → 10,128 句，≥8 詞佔比 10.4% → **25.1%**。dev 不重複以免評估失真。

### 語料庫長句（同一份 60 句，同 seed）

| 指標 | v9 | **v10** | 變化 |
|---|---:|---:|---|
| Exact Match | 8.33% | **21.67%** | **×2.6** |
| BLEU-4 | 27.41 | **52.73** | ×1.9 |
| ROUGE-L | 59.02 | **69.43** | +10.4 |
| 完全正確句數 | 5 | **13** | +8 |
| 輸出過短比例 | 70% | **46.7%** | −23.3pp |
| 情態詞遺漏 | 10% | **3.3%** | −6.7pp |
| 否定詞形不符 | 1.7% | **0%** | — |

### 使用者回報的 3 句：**全部完全正確**

| 中文 | v10 輸出 | 正確？ |
|---|---|---|
| 我朋友跟她先生兩個人都要上班，沒有辦法照顧 | 我 朋友 先生 兩個人 上班 要 照顧 沒辦法 | ✅ |
| 要帶這四樣：戶口名簿、印章、身分證，還有兩吋照片 | 戶口名簿 印章 身分證 照片 二 吋 這四樣 帶 要 | ✅ |
| 胃鏡檢查前至少8小時不能進食、喝水或服藥 | 胃鏡 檢查 之前 八個小時 吃 水 喝 服藥 任何 禁止 | ✅ |

先前 v9 在這三句分別漏「要」、清單未前置、漏「水」，現已全部修正。

## 4. ⚠️ 代價：極短語退步

核心 33 句 test（**參考答案平均僅 2.39 詞**，多為「你好／早安」等問候語）：

| 指標 | v8 | v9 | **v10** |
|---|---:|---:|---:|
| Exact Match | 75.76% | 69.70% | **57.58%** |
| BLEU-4 | 82.47 | 69.47 | 71.88 |

逐句比對 v9→v10：**變好 1 句、變差 5 句**

| 句 | ref | v9 | v10 |
|---|---|---|---|
| 你好 | 你/好 | 你/好 ✓ | 你好（未拆） |
| 早安 | 早安 | 早安 ✓ | 早上/好 |
| 我聽不懂 | 我/聽/不懂 | 我/聽/不懂 ✓ | 我/不懂（漏「聽」） |
| 我要這個 | 我/這/要 | 我/這/要 ✓ | 我/要（漏「這」） |
| 我要看醫生 | 我/看醫生/要 | 我/去/看/醫生/要 | 我/看醫生/要 ✓ |

**這是真實的取捨，不是雜訊**（5 句同向變差）。長度平衡讓模型學到「中文長→Gloss 長」
的對應，對極短輸入反而過度壓縮。

## 5. 建議：採用 v10，但知道其適用範圍

- **實際使用情境是完整句子**（使用者測的都是長句），v10 明顯較佳。
- 核心 33 句是問候語與短片語，**不代表真實輸入分布**；它在 Stage A/B 有歷史可比性
  的價值，但不該作為唯一取捨依據。
- 若短語準確度也重要，可調降平衡強度（如 5–7 ×1.5、≥8 ×2）再訓一版，取折衷點。
  此為單一參數，成本一輪訓練。

## 6. 據實記錄的方法學限制

**語料庫句子全部在訓練集內**（2026-08-05 政策決定），故第 3 節的 60 句稽核量的是
**復現能力，不是泛化能力**。改善復現不等於改善對未見句子的表現。

要嚴謹衡量泛化，需留一批語料庫長句作測試集（代價：那些句子不能進訓練）。
`split_data.py --corpus-test-ratio` 已具備此功能，建議下一輪啟用。

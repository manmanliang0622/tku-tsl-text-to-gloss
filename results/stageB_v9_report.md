# Stage B v9：修正 WH 標註 bug 後重訓

日期：2026-08-07
起因：使用者實測「前幾天我喝水、吃東西的時候覺得牙齒很痛耶」翻錯，追查後發現
**訓練標籤本身就是錯的**。

## 1. Bug 與修正

`build_json_targets.py` 把「幾」列為無條件疑問詞，導致「前**幾**天」「好**幾**次」
「二十**幾**年」等被標成 wh 疑問句並配上「疑問表情」NMS。

實測訓練資料 **42 句含「幾」，其中 31 句（74%）並非疑問句**。

| | 含「幾」句的疑問判定準確率 |
|---|---:|
| 修正前 | 26.2%（11/42） |
| **修正後** | **90.5%（38/42）** |

修法：①「幾」移出 WH_HINTS 改列歧義詞，先剔除固定用法（前幾／好幾／這幾／那幾／
幾乎／十幾／數字+幾／幾百千萬／零星幾）；②剔除後仍有「幾」時需有疑問標點或語氣詞
佐證；③「哪」細化為 哪裡／哪個／哪一。全資料 6,135 句中 **45 句（0.7%）標籤被修正**。

## 2. 一個 bug 造成兩種錯誤

使用者例句在 v8／v9 的輸出：

| | v8（bug 未修） | v9（已修） |
|---|---|---|
| 輸出 | `我/喝水/吃東西/牙齒/痛/`**`幾天`** | **`前幾天`**`/我/喝水/吃東西/牙齒/痛` |
| question_type | **wh**（錯） | **none** ✓ |
| nonmanual | 「疑問表情搭配句末疑問詞」（錯） | none ✓ |

**時間詞位置也一併修好了。** 因果關係：規則 7 是「疑問詞置句末」，v8 既然把這句
誤判為 wh 疑問句，就把含「幾」的「幾天」搬到句末當疑問詞處理。**單一標註 bug
同時汙染了 NMS 與語序**——這也說明標籤品質問題會以難以預期的方式擴散。

殘留錯誤（與本次修正無關）：複合詞未拆（`喝水` 應為 `水/喝`）、多餘主語「我」。

## 3. 33 句 test 結果與其侷限

| 指標 | v8 | v9 |
|---|---:|---:|
| BLEU-4 | 82.47 | 69.47 |
| ROUGE-L | 88.20 | 85.67 |
| Exact Match | 75.76% | 69.70% |
| 可播放率 | 97.18% | 97.22% |
| 有效 JSON | 100% | 100% |
| 疑問類型正確 | 100% | 100% |
| **否定判斷正確** | 96.97% | **100%** |
| 輸出 NMS 比例 | 33.33% | 30.30% |

**這個測試集無法測出本次修正的效益，理由有二：**

1. **逐句比對顯示 v8／v9 只有 2 句不同，且都與「幾」無關**：

   | 句 | v8 | v9 |
   |---|---|---|
   | 我知道 | 我/知道 ✓ | 知道 ✗（掉主語） |
   | 我要看醫生 | 我/看醫生/要 ✓ | 我/去/看/醫生/要 ✗（過度切分） |

   兩句皆不含「幾」，屬**重訓的 run-to-run 變異**（45 句標籤改變→梯度改變→
   權重不同→無關句子輸出也可能變），非修正造成的退步。EM 少 6 個百分點＝
   2 句／33 句，在此樣本量下即為雜訊。

2. **33 句中唯二含「幾」的是 S21「現在幾點」與 S22「今天星期幾」，本來就是疑問句**，
   修正前後判定相同（故兩版 QuestionAcc 皆 100%）。測試集裡沒有「前幾天」這類受害句型。

修正的效益只在**語料庫風格的長句**上顯現，而那類句子已全部進訓練、沒有留存測試集
（見 HANDOFF 2026-08-05 政策變更的代價說明）。

## 4. 建議採用 v9

理由：
- 標籤正確性是資料品質問題，**即使自動指標看不出來也該修**；錯誤標籤會持續汙染
  往後每一次訓練。
- 否定判斷 96.97% → 100%。
- 使用者實測的句型確實改善（時間詞位置＋NMS）。
- 33 句 test 的 −6 EM 已證實為 2 句無關句子的隨機變異。

⚠️ 但需誠實記錄：**目前沒有能驗證此修正的測試集**。要嚴謹證明，需另留一批
含「前幾天／好幾次」等句型的語料庫句子作測試，或做人工評估。

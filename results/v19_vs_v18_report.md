# v19 vs v18 報告（2026-09-04）

v19 = v18 的資料 + `--min-coverage 0.8`（只用參考詞涵蓋率 ≥0.8 的句子訓練，
5,545 列，為 v18 的 61%）。其餘完全相同：k=60、LOGO、schema v3、排除不可播資產。
checkpoint-347（epoch 1；eval_loss ep1 0.1872 / ep2 0.2502，第二個 epoch 過擬合，
與 v17／v18 同樣的模式）。門檻 0.067544（新 dev 上最大化 F1，F1 0.7181）。
約束解碼開啟，manifest 記錄 commit `e34d9c1`。

## 一句話

**假設的機制成立，但矯枉過正。** v19 確實學會多輸出，也確實選回了人工評估
點名漏掉的詞——但同時多出錯詞，自動指標因此下降。人會不會偏好「較完整但帶
雜詞」勝過「精簡但漏詞」，只有盲測能答，表已產好。

## 一、假設驗證：三條證據都指向「機制成立」

v18 的問題被診斷為：訓練目標被截短 21.1% → 模型學會少輸出。v19 把截短率壓到
6.6%。預期是輸出變長、漏詞減少。實測：

**① 輸出長度回升了**（平均 sign 數）

| 資料集 | 參考 | v17 | v18 | **v19** |
|---|---:|---:|---:|---:|
| 核心 33 | 2.36 | 1.97 | 2.12 | **2.15** |
| test_corpus | 5.30 | 5.89 | 5.62 | **6.34** |
| test_textbook | 3.71 | 4.26 | 3.92 | **4.42** |

**② 人工點名的漏詞被選回來了。** v17/v18 盲測中評分者點名「有候選卻沒選」的
68 個詞，各版實際選到的比例：

| | v17 | v18 | **v19** |
|---|---:|---:|---:|
| 選到 | 37（54%） | 25（37%） | **40（59%）** |

這是最直接的驗證——量的是人抱怨的那 68 個案例本身，不是代理指標。
v19 不只修回 v18 的退步，還超過 v17。

**③ token 層 recall 上升**（多選到參考詞）

| 資料集 | | v17 | v18 | **v19** |
|---|---|---:|---:|---:|
| textbook | recall | 0.772 | 0.770 | **0.809** |
| corpus | recall | 0.726 | 0.710 | **0.725** |

## 二、但矯枉過正：precision 掉了，BLEU 跟著掉

| 資料集 | | v17 | v18 | v19 |
|---|---|---:|---:|---:|
| textbook | precision | 0.672 | **0.725** | 0.676 |
| | F1 | 0.719 | **0.747** | 0.736 |
| corpus | precision | 0.653 | **0.697** | 0.638 |
| | F1 | 0.688 | **0.703** | 0.679 |

輸出從「參考 3.71」衝到 4.42——**超產**了。多出來的詞有一部分是參考沒有的
（precision ↓），BLEU 直接懲罰這個：

| 資料集 | BLEU-4 | v17 | v18 | v19 | v19−v18 |
|---|---|---:|---:|---:|---:|
| 核心 33 | | 73.80 | 72.78 | 65.68 | **−7.10** |
| test_corpus | | 26.51 | 24.93 | 25.47 | +0.54 |
| test_textbook | | 29.65 | 34.02 | 27.32 | **−6.70** |

核心 33 的 −7.10 要打折看（n=33），但教材集 −6.70（n=423）是真的。

退化輸出也略增：破 JSON 1→3、連續重複 ≥4 的 1→3（622 句中，絕對數小但翻了三倍）。

## 三、為什麼自動指標不能當最終裁判

v18 那輪已經證明過一次：教材集 BLEU +4.37 的同時，人工盲測 v18 只贏 33%
（p=0.099）。BLEU 與人的判斷在這個任務上會反向。

而 v19 的情況更微妙——它多出的詞裡，有些是參考沒寫但其實合理的（人工評估
已證實參考本身會漏詞），有些是真的錯。BLEU 一律扣分，人不會。

**所以 v19 到底有沒有比 v18 好，要看盲測。** 表已在 `outputs/盲測_v18script_vs_v19script.xlsx`
（87 題：教材 40、語料庫 40、核心 7；A 欄 v18 42 題／v19 45 題；無版本洩漏）。

## 五、結論與建議

| | 結論 |
|---|---|
| 診斷（目標截短→少輸出） | **正確**，三條獨立證據 |
| 修法方向（減少截短） | **正確**，漏詞由 37% 回到 59% |
| 修法力道（門檻 0.8） | **過頭**，precision 掉、超產 |
| v19 該不該部署 | **先不要**，等盲測 |

下一步建議兩條並行：

1. **盲測 v18 vs v19**——這是唯一能決定的方法。若 v19 勝，超產是可接受的代價；
   若 v18 勝，代表人也不喜歡雜詞，要往中間調。
2. **準備 v20 = `--min-coverage 0.7`**——0.7 留 72% 資料、截短率 10.5%，介於
   v18（21.1%）與 v19（6.6%）之間。如果盲測顯示 v19 過頭，v20 是現成的中間值。
   建資料 15 分鐘，不需要等盲測回來就能先建好。

線上目前仍是 v18。v19 不部署。
